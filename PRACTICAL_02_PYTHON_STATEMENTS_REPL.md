# Python REPL and IDLE Practical Execution Guide

## Introduction
This document provides a practical execution guide for utilizing Python's REPL (Read-Eval-Print Loop) and IDLE (Integrated Development and Learning Environment).

## Getting Started with Python REPL
1. **Open Terminal or Command Prompt**:
   - To access Python REPL, you can open a terminal (Linux or macOS) or command prompt (Windows).

2. **Launch Python**:
   - Type `python` or `python3` in your terminal and press Enter. You should see the Python shell starting up with the version number.

   ![Python REPL Start](link_to_screenshot_1)

### Example Commands in REPL

- **Basic Arithmetic**:
  ```python
  >>> 5 + 5
  10
  ```

- **Defining a Function**:
  ```python
  >>> def greet(name):
  ...     return f'Hello, {name}!'
  >>> greet('World')
  'Hello, World!'
  ```

## Using IDLE
1. **Open IDLE**:
   - You can start IDLE by searching for it from your applications or typing `idle` in your terminal.

2. **Creating a New File**:
   - Click on `File` > `New File` to create a new Python script.
   - Write your code in the new window.

3. **Execute the Python Script**:
   - Save your script with a `.py` extension, then run it by clicking on `Run` > `Run Module` or by pressing `F5`.
