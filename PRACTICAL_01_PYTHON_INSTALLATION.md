# Python Installation Guide for Windows OS

## Step 1: Download the Python Installer
1. Go to the official Python website: [python.org](https://www.python.org/downloads/).
2. Click on the "Download Python" button. The latest version will be displayed.

![Download Python](link-to-screenshot)

## Step 2: Run the Installer
1. Locate the downloaded installer file (e.g., `python-3.x.x.exe`) in your Downloads folder.
2. Double-click the installer to run it.

![Run Installer](link-to-screenshot)

## Step 3: Customize Installation
1. In the installer window, check the box that says **Add Python 3.x to PATH** at the bottom.
2. Click on **Customize installation** to see options.

![Customize Installation](link-to-screenshot)

## Step 4: Choose Optional Features
1. Ensure the following features are checked:
   - pip (Package installer for Python)
   - IDLE (Python Integrated Development Environment)
   - Documentation
   - Test suite
   - py launcher

![Optional Features](link-to-screenshot)

2. Click **Next**.

## Step 5: Advanced Options
1. Leave the options as default or customize as needed.
2. Click on **Install** to start the installation process.

![Advanced Options](link-to-screenshot)

## Step 6: Wait for Installation
- The installer will now install Python and pip on your system. This may take a few minutes.

![Installation Progress](link-to-screenshot)

## Step 7: Verify Installation
1. Open Command Prompt (search for "cmd" in the Start menu).
2. Type `python --version` and press Enter.
3. You should see the installed Python version.

![Verify Installation](link-to-screenshot)

## Step 8: Install a Package Using pip
1. In Command Prompt, type `pip install <package-name>` to install packages.
   - Example: `pip install requests`

## Conclusion
You have successfully installed Python on your Windows system. You can now start developing Python applications!
